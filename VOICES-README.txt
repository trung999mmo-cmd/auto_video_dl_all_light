THU MUC VOICES

1. Piper Offline
- Tool se kem san 1 model Tieng Viet: vi_VN-vais1000-medium.
- Muon them giong Piper khac, chep DU 2 file vao thu muc voices:
  ten_giong.onnx
  ten_giong.onnx.json
- Sau do mo tool va bam Lam moi giong.

2. Voice Clone tu audio mau
- Day KHONG phai model Piper.
- Chay INSTALL-VOICE-CLONE.bat mot lan.
- Trong tool chon He giong = Voice Clone XTTS, sau do chon file WAV/MP3 giong mau.
- Model XTTS co danh sach ngon ngu rieng; neu model khong ho tro ngon ngu da chon, tool se bao loi thay vi gia lap sai.

3. Bao mat
- Khong dat API key hay TikTok sessionid vao thu muc nay.
